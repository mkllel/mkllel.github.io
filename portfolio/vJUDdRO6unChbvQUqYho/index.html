B2B SaaS · 업무 자동화 · 백엔드

어린이집 B2B 행정 자동화 플랫폼 — 증명서24

여러 공공기관의 서류 신청, 발급, 다운로드 절차와 어린이집 행정 업무를 하나의 웹 서비스 흐름으로 연결했습니다. 기관 웹사이트에서 진행해야 하는 인증, 신청, 발급 절차에는 Selenium 기반 브라우저 자동화를 적용했습니다. 장시간 작업의 상태와 실패 지점을 추적할 수 있도록 FastAPI 기반 백엔드 구조를 설계했습니다.

담당
백엔드 API, 기관별 브라우저 자동화, 작업 상태 관리, 사용자와 기관 및 증명서 데이터 모델을 설계하고 구현했습니다. 제공받은 디자인과 퍼블리싱 산출물을 바탕으로 React/TypeScript 프론트엔드를 개발하고 API를 연동했습니다. 해당 개발 범위는 단독으로 담당했으며, 테스트 서버 및 DB 환경과 Docker 실행 환경도 구성했습니다.
기술
Python · FastAPI · SQLAlchemy · PostgreSQL · Selenium · AWS S3 · React · TypeScript · Vite · Docker · Git
결과
기관별로 반복하던 인증, 신청, 발급 확인과 파일 다운로드 절차를 웹 서비스에 연결했습니다. 장시간 작업의 진행 상태와 오류를 조회할 수 있도록 구성하고 결과를 웹 화면과 다운로드 파일로 제공했습니다. 증명서 발급뿐 아니라 교직원, 인사기록, 보육료, 지원금 등 어린이집 행정 업무를 처리하는 자동화 기능도 개발했습니다.

기관별 인증과 화면 처리 로직은 자동화 모듈에 두고 웹 API는 요청 전달과 상태 조회, 결과 제공을 담당하도록 구성했습니다.

01

해결해야 했던 문제

사용자는 정부24, 대법원 전자가족관계등록시스템 등 여러 사이트에 각각 접속해 인증하고 필요한 서류를 신청해 발급받아야 했습니다.

어린이집 운영에 필요한 교직원, 아동, 보육료, 지원금, 회계 정보도 별도 시스템에서 확인해야 했습니다. 이 때문에 로그인, 조회, 파일 처리 작업을 반복해야 했습니다.

기관마다 인증 방식과 화면 구조가 달랐고 일부 작업은 사용자 인증이나 발급 완료까지 기다려야 했습니다. 외부 사이트의 응답 지연이나 화면 변경으로 작업이 실패하면 어느 단계에서 문제가 발생했는지도 확인할 수 있어야 했습니다.

02

주요 구현

기관별 브라우저 자동화

Selenium으로 기관별 로그인, 메뉴 이동, 정보 입력, 신청 및 발급 확인과 결과 수집 로직을 구현했습니다.

간편인증이 필요한 작업은 사용자 인증이 완료된 뒤 다음 단계로 진행하도록 구성했습니다.

  • 정부24: 주민등록등본, 보육교사 경력증명서, 소득금액증명서 등 신청 및 발급
  • 대법원: 기본증명서와 가족관계증명서 발급 및 결과 처리
  • 범죄경력 조회: 신청 및 확인 단계 처리와 회보서 결과 수집
  • 보육통합정보시스템: 교직원과 아동 정보, 인사기록카드, 보육료, 지원금, 회계 관련 업무 처리
  • 고용24: 사업주훈련과 기업직업훈련카드 관련 정보 조회

장시간 작업의 상태 관리

장시간 실행되는 자동화 작업에 작업 ID를 부여하고 요청 접수와 실제 실행 흐름을 분리했습니다.

대기, 실행, 성공, 실패 상태와 결과 및 오류 메시지를 관리하고 상태 조회 API로 제공했습니다.

React 화면에서는 작업 상태를 주기적으로 조회해 진행 상황을 표시했습니다. 완료 시 결과를 반영하고 실패 시 오류 메시지를 안내하도록 구현했습니다.

외부 자동화 서버 연동 및 오류 처리

FastAPI에서 기관별 자동화 서버로 요청을 전달하고 응답 데이터를 웹 서비스에서 사용할 수 있는 형태로 처리했습니다.

연결 실패, 응답 시간 초과, 응답 형식 오류 등 외부 연동 문제를 구분해 API 오류로 반환했습니다. 작업이 실패하면 상태와 오류 상세를 함께 제공하도록 구성했습니다.

사용자·기관·증명서 데이터 관리

SQLAlchemy로 사용자, 기관, 소속 관계와 증명서 데이터를 모델링했습니다.

한 사용자가 여러 기관에 소속될 수 있도록 사용자–기관 관계와 기관별 역할을 관리했습니다. 증명서 조회 및 제출 API에는 사용자 소유권, 기관 소속 및 역할에 따른 권한 검사를 적용했습니다.

공통 파일 다운로드 API에는 토큰 기반 인증을 적용했습니다.

React 프론트엔드와 API 연동

제공받은 퍼블리싱 산출물을 기반으로 회원가입과 로그인, 사업장 관리, 증명서 발급 및 제출 내역과 어린이집 행정 업무 화면을 React/TypeScript로 구현했습니다.

화면 입력값을 API 요청으로 전달하고 응답에 따라 진행 상태, 오류, 결과를 표시하도록 연결했습니다.

결과 파일과 실행 환경

자동화 결과를 데이터와 파일로 저장하고 웹 조회 및 다운로드 API에 연결했습니다.

증명서 자동화에는 AWS S3 업로드와 저장된 파일 조회 기능을 구현했습니다.

Dockerfile에 애플리케이션 의존성 설치와 서버 실행 절차를 정의하고 개발 및 연동 확인을 위한 테스트 서버와 PostgreSQL 환경을 구성했습니다.

03

회고 및 개선점

기관마다 화면 구조와 인증 절차가 달라 외부 사이트 변경에 대응하는 유지보수가 중요한 과제였습니다.

기관별 처리 코드를 분리하고 작업 상태와 오류를 확인할 수 있도록 구성했지만 변경에 더 안정적으로 대응하려면 단계별 검증과 실패 기록을 더욱 체계화할 필요가 있습니다.

일부 비동기 작업은 서버 프로세스 메모리에서 상태를 관리하도록 구현했습니다. 후속 개선에서는 작업 상태를 영속적으로 저장하고 별도 작업 큐와 워커를 도입해 서버 재시작 시 상태 유실을 방지하고 동시 작업 처리를 개선할 수 있습니다.

파일 접근 제어도 모든 다운로드 경로에서 사용자 소유권과 기관 권한을 일관되게 검증하도록 보완할 수 있습니다.

회사 프로젝트이므로 소스코드와 운영 주소는 공개하지 않고 담당 범위와 설계 구조를 중심으로 소개합니다.

다른 경험도 문제와 담당 범위를 기준으로 정리했습니다.
